# Pluto 1.0.0-rc.17

Release candidate for testing. Includes changes since the last published release, rc.11.

## Changes

- Keep recordings running through quiet meeting breaks and check the original call source before automatically ending a recording.
- Add commitment reminders and refine connected meeting intelligence.
- Fix sidebar update startup and failure feedback.
- Isolate both source startup commands under Pluto Development, with a separate profile and app identity.
- Preserve the active profile and its Standard or Encrypted storage choice across updates. Reject installer downgrades and explain when a database requires a newer app.
- Freeze established migration history and add upgrade regressions that preserve existing data and key envelopes.
- Require full tests before merging to master and verify the exact release commit's packaged installer before creating its tag.
- Publish installers through a resumable draft with fail-closed API handling; use a fresh release version to recover from the reserved rc.16 tag.

## Installation

Install in one Terminal command:

```sh
curl -fsSL https://raw.githubusercontent.com/metagrover/pluto/master/scripts/install-macos.sh | bash
```

While the repository is private, use authenticated GitHub CLI instead:

```sh
gh api -H 'Accept: application/vnd.github.raw+json' repos/metagrover/pluto/contents/scripts/install-macos.sh | bash
```

The installer downloads, verifies SHA256SUMS.txt and the app signature, installs, removes only Pluto's quarantine, and launches. Running it explicitly trusts Pluto. Profiles, models, and system-wide Gatekeeper protection are preserved. Ad-hoc signed upgrades reset only Pluto permission decisions when the code identity changes, so macOS can request access for the new build. Or download the attached Apple Silicon DMG to install manually. The current build is ad-hoc signed and is not notarized. Existing profiles are preserved; keep a backup before upgrading.
