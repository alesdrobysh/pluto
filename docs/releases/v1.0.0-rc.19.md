# Pluto 1.0.0-rc.19

Release candidate for testing.

## Changes

- Updates now download and verify before quitting, show shared progress, handle repeated clicks safely, and recover from blocked quit or failed installation. Startup confirms the installed version before reporting completion. (#869)
- Recording shutdown is bounded and acknowledged, and stopped capture ownership is released even if persistence fails. (#868)

## Upgrade notes

Existing meetings, settings, and downloaded models are preserved. Full-app standard and encrypted profile upgrades, database migrations, and microphone/system-audio permission recovery were verified on Apple Silicon macOS.

These fixes take effect after installation. An older app already stuck updating may need a one-time manual install. In rc.11, the old in-app updater does not preserve a custom profile on relaunch: custom-profile users should use the installer with `--user-data-dir` set to their existing absolute profile path. Normal default-profile users can use the in-app update.

Ad-hoc signature changes reset only Pluto's macOS permissions. If microphone access remains blocked, refresh Pluto's microphone grant in System Settings and restart Pluto. This build is ad-hoc signed and is not notarized.

## Installation

```sh
curl -fsSL https://raw.githubusercontent.com/metagrover/pluto/master/scripts/install-macos.sh | bash
```

While the repository is private, use authenticated GitHub CLI:

```sh
gh api -H 'Accept: application/vnd.github.raw+json' repos/metagrover/pluto/contents/scripts/install-macos.sh | bash
```

The installer verifies checksums, app identity, version, and signature before replacement. Running it explicitly trusts Pluto and removes only Pluto's quarantine; system-wide Gatekeeper protection is preserved. Keep a backup before upgrading. The attached DMG is for Apple Silicon Macs.
